## Approved material to project

### 1. Core commercial translation

Approved thesis:

> Do not lead by selling Emergence Theory. Lead with the applied instrument.

Approved offer language:

```text
Boundary / Defect / Invariant Audit for consequence-bearing systems
```

Useful plain-language behavior:

- identify where responsibility changes hands;
- identify where state or evidence is lost;
- identify authority drift;
- identify invariants that must survive transitions;
- identify downstream defect propagation;
- identify repair paths and escalation ownership.

This should make `/agency-audit` more legible as something an organization can actually buy without reducing the service to generic consulting copy.

### 2. Core question

Approved source question:

> **What must remain true when this system crosses an interface?**

This pairs naturally with the existing Agency Audit questions:

- who or what may act;
- what representation authorizes or informs action;
- what consequence follows;
- whether an affected party can contest it;
- who owns repair.

The local pass should find the cleanest way to expose both levels without making the page feel repetitive.

### 3. Deliverable vocabulary

Approved source deliverables include:

- boundary map;
- defect ledger;
- invariant register;
- workflow risk map;
- prioritized repair roadmap;
- optional pilot scope;
- evidence summary.

The current service already promises:

- agency map;
- representation map;
- consequence chain;
- contest path;
- repair ownership map;
- defect register.

Do not simply concatenate both lists.

Refine them into a single output system. A plausible structure is:

```text
System map
  - agency / authority map
  - representation + boundary map

Consequence analysis
  - consequence chain
  - invariant register
  - defect ledger

Repair package
  - contest / escalation path
  - repair ownership map
  - prioritized repair roadmap

Optional next step
  - bounded pilot / deployment-control scope
```

Treat that as a working model, not mandatory wording.

### 4. Flagship near-term wedge

The approved flagship wedge is:

> **Agentic Boundary Audit for consequence-bearing AI**

This should probably begin as a visible specialization or example within `/agency-audit`, not as a new top-level product.

Approved concerns include:

- external state changes;
- escalation;
- accountability;
- human override;
