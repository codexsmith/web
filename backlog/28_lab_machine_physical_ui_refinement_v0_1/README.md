# Workstream 28 — BFL Lab Machine Physical UI Refinement v0.1

**Status:** Design-ready / implementation open

This package defines a coherent Lab Machine feature set built from three connected physical UI elements:

- **Forge** — standalone digital fabrication machine installed above Tour;
- **Research Engine** — central Research module refined as purple smoked plexiglass with machined metal bindings;
- **Research Exhaust** — physically grounded live research telemetry/output ticker below the research machinery.

Start with `BACKLOG_REQUIREMENTS.md`. `STATUS.md` is the current workstream-status authority.

## Repository relationships

This workstream extends, rather than replaces, existing machinery:

- workstream **19** for apparatus restraint and physical hierarchy;
- workstream **23** for Lab Machine visual grammar and governed-object machinery;
- workstream **11** for live-research concepts that may later feed Research Exhaust.
