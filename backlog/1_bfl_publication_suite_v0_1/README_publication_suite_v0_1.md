# Boundary First Labs Publication Suite v0.1

## Purpose

This suite packages the Civilizational Mechanics / Boundary First Labs learning pathway into high-value publication formats: doctrine brief, implementation brief, slide deck source, website content pack, visualization registry, and canonical data artifacts.

## Publication assets

| Asset | File | Use |
|---|---|---|
| Doctrine brief | `bfl_civilizational_mechanics_doctrine_brief_v0_1.docx` / `.pdf` | Public doctrine, partner/funder brief, website source copy |
| Learning pathway implementation brief | `bfl_learning_pathway_implementation_brief_v0_1.docx` / `.pdf` | Product/design handoff for the explorable atlas experience |
| Slide deck | `bfl_civilizational_mechanics_slide_deck_v0_1.pptx` / `.pdf` | Presentation, pitch, meeting, voiceover draft |
| Web content pack | `bfl_public_web_content_pack_v0_1.json` | Cards, homepage hero, expanded doctrine, repair routes |
| D3 visualization registry | `bfl_d3_visualization_registry_v0_1.json` | Implementation guidance for relation-specific projections |
| Canonical learning pathway | `bfl_civilizational_mechanics_learning_pathway_v0_1.json` | Source data for app/atlas rendering |
| Schema | `bfl_learning_pathway_schema_v0_1.json` | Validation contract |
| Notes | `bfl_civilizational_mechanics_learning_pathway_notes_v0_1.md` | Architecture and implementation notes |

## Core thesis

> Civilization is an executable representation that must learn to revise itself before it fails beneath its own model.

## Recommended publication sequence

1. Use the doctrine brief as the public concept source.
2. Use the slide deck for live explanation and partner conversations.
3. Use the web content pack to implement cards and expanded doctrine in the website.
4. Use the pathway JSON and visualization registry to build the interactive learning path.
5. Promote individual claims only after source/provenance review and public-copy pass.

## Claim ceiling

Public doctrine and operational orientation. The pathway explains and applies the current framework; it does not by itself establish formal or empirical claims.
