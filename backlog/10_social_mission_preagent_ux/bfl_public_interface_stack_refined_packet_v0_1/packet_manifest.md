# Packet Manifest — Public Interface Stack v0.1

## Group identity

**Working group:** Public Interface Stack  
**Status:** editorial grouping, not a new canonical theory layer  
**Purpose:** refine the machinery that transports Boundary First Labs material from source/corpus form into navigable, visual, public web form.

## Included source packets

1. `02_Boundary_First_UX.md` — interaction and resolution-navigation doctrine.
2. `12_Webpage.md` — implementation scaffold and visual-identity/design language.
3. `website_packet.md` — curated public content and homepage/cosmic-shore projection.

## Preserved distinction

```text
Boundary First UX
    governs how a representation may be navigated
            ↓
Web / visual interface
    governs how the interaction system is embodied and styled
            ↓
Website content projection
    governs what public material is shown, sequenced, and linked
```

No layer may silently inherit authority from the one upstream or downstream of it.
