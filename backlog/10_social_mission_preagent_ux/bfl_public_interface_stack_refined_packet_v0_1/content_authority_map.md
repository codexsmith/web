# Content Authority and Projection Map

## Authority order

1. **Canonical/refined source artifacts** own definitions, institutional commitments, claims, evidence, and project status.
2. **Public content projections** select, sequence, compress, and contextualize those artifacts for a reader.
3. **Boundary First UX** governs navigation and representational transitions.
4. **Web implementation** renders the projection and interaction grammar.
5. **Visual identity** supplies recognizable presentation registers.

## A website page may own

- navigation labels;
- explanatory summaries;
- audience-specific sequencing;
- calls to action;
- visual hierarchy;
- interaction state;
- presentation metadata.

## A website page should reference rather than independently own

- canonical definitions;
- claim maturity;
- evidence status;
- project affiliation/partnership status;
- research conclusions;
- institutional doctrine;
- historical provenance.

## Governing rule

> The public interface may compress the representation, but it must not silently change the represented object.
