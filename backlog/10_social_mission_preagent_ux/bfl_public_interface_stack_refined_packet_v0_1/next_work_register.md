## Definition of done for a public page

A public page is closed only when:

- its represented object is identified;
- current naming is verified;
- claim status is preserved;
- source/provenance is recoverable;
- active filters/compressions are legible where relevant;
- keyboard/mobile/reduced-motion paths exist;
- links and project status are current;
- a correction/update path exists.
