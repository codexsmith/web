# Spatial Research Environment Specification

## Core proposition

> Corpus Forge should feel like entering a place where inquiry has architecture, evidence has location, claims have weight, contradictions occupy space, and promotion requires crossing a visible boundary.

## Design boundary

The spatial environment is not a decorative metaverse or forced game layer. Every operational room, object, path, barrier, and environmental effect must bind to real semantic state, workflow, or authority.

## Room model

### 1. Threshold / Entry Hall

- orientation;
- role and intent selection;
- current identity and authority;
- entry into public, research, or restricted paths.

### 2. Central Workbench

- active inquiry state;
- current artifacts;
- familiar and expanded method cycles;
- composition, linking, and next action.

### 3. Instrument Gallery

- methods;
- models;
- tools;
- calibration;
- compatibility and method requirements.

### 4. Experiment Chamber

- frozen protocol;
- execution;
- live trace;
- deviations;
- controlled conditions.

### 5. Correspondence Hall

- represented versus observed;
- claims and sources;
- comparison;
- contradictions;
- coordination and citation.

### 6. Repair Forge

- defect localization;
- repair branch;
- affected dependencies;
- preserved failed state;
- retest requirements.

### 7. Review Chamber

- critic report;
- review packet;
- unresolved decisions;
- human authority;
- promotion gate.

### 8. Archive

- canonical and superseded artifacts;
- lineage;
- versions;
- negative results;
- reopening conditions.

### 9. Observatory / Atlas

- program and domain scale;
- distant contexts;
- knowledge topology;
- external institutions;
- public projection.

## Object vocabulary

| Spatial object | Semantic object |
|---|---|
| Document or scroll | Source/document |
| Specimen card | Observation/entity/extract |
| Illuminated claim object | Claim/model/hypothesis |
| Result panel | Trace/result/analysis |
| Tension link or crack | Contradiction/defect |
| Packet bundle | Review packet |
| Sealed volume | Promoted or restricted artifact |
| Tool/instrument | Method, test, transformation |
| Gate | Authority or validation requirement |
| Scaffold | Provisional structure |
| Dark passage | Unknown/unresolved/unobserved region |

## Environmental status language

- supported: stable, connected, load-bearing;
- provisional: scaffolded or translucent;
- contradicted: visible tension between objects;
- missing provenance: suspended/unanchored;
- negative result: complete route with terminal state;
- restricted: enclosed and role-gated;
- superseded: preserved behind or beneath current object;
- promotion-ready: staged before a closed gate;
- open question: incomplete chamber/path with declared entry conditions.

## Scale model

```text
Object → Room → Inquiry → Program → Domain → Lab → Atlas
```

Selection and context should persist across scale changes.

## Modes

- Immersive mode;
- Workbench mode;
- Atlas mode;
- accessible list/text mode.

No user should need to walk through a virtual room to perform a routine operation.
