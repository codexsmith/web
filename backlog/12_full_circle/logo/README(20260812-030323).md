# Boundary First Wave Logo — React + CSS Variables

A dependency-free React/TypeScript component built from the transparent SVG mark.

## Files

- `BoundaryFirstWaveLogo.tsx` — drop-in React component.
- `boundary-first-wave-logo.css` — semantic variable contract + optional presets.
- `LogoPlayground.tsx` — interactive five-color example for Next.js/React.
- `boundary-first-wave-logo.cssvars.svg` — raw SVG using the same semantic variables.
- `index.ts` — convenience export.

## Semantic color contract

The public palette has five roles:

```css
--bf-boundary
--bf-field
--bf-depth
--bf-witness
--bf-spark
```

The original artwork has one additional transitional wave. It is derived automatically:

```css
--bf-field-mid: color-mix(in srgb, var(--bf-field) 62%, var(--bf-depth));
```

You can override `--bf-field-mid` manually when exact art direction is needed.

## Basic React usage

```tsx
import { BoundaryFirstWaveLogo } from "./BoundaryFirstWaveLogo";

export default function Header() {
  return (
    <BoundaryFirstWaveLogo
      boundary="#0B1F3A"
      field="#527C80"
      depth="#334155"
      witness="#C8A24A"
      spark="#C8A24A"
      style={{ width: 220 }}
    />
  );
}
```

`witness` and `spark` default to the `boundary` color, so the common three-color form is simply:

```tsx
<BoundaryFirstWaveLogo
  boundary="#1A254B"
  field="#4E7376"
  depth="#304B5E"
/>
```

## CSS-controlled usage

```tsx
import "./boundary-first-wave-logo.css";

<BoundaryFirstWaveLogo className="bf-wave-logo" />
```

Then configure from CSS:

```css
.my-brand .bf-wave-logo {
  --bf-boundary: #0b1f3a;
  --bf-field: #527c80;
  --bf-depth: #334155;
  --bf-witness: #c8a24a;
  --bf-spark: #c8a24a;
}
```

The component merges its defaults first and the supplied `style` object second, so inline CSS variables can override any prop/default:

```tsx
<BoundaryFirstWaveLogo
  style={{
    "--bf-spark": "hotpink",
    "--bf-field-mid": "#466A71",
  } as React.CSSProperties}
/>
```

## Presets

The CSS file includes these optional `data-theme` presets:

```tsx
<BoundaryFirstWaveLogo className="bf-wave-logo" data-theme="statesman" />
<BoundaryFirstWaveLogo className="bf-wave-logo" data-theme="systems" />
<BoundaryFirstWaveLogo className="bf-wave-logo" data-theme="feral" />
<BoundaryFirstWaveLogo className="bf-wave-logo" data-theme="monochrome" />
```

## Next.js

The logo component itself does **not** require `"use client"`; it can render as a Server Component. Only the included `LogoPlayground.tsx` uses client state.

For runtime color pickers, render the SVG inline through the React component. Do not use the logo only through `<img src="...">` when you need parent-page CSS variables to recolor it.

## Accessibility

Normal use:

```tsx
<BoundaryFirstWaveLogo title="Boundary First Labs" />
```

Decorative use:

```tsx
<BoundaryFirstWaveLogo decorative />
```
