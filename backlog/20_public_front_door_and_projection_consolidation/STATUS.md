## Current Process posture

The Lab-root **Timeline** remains a useful temporal projection.

The generic non-root **Process** control is intentionally hidden for now. Direct Process URLs and the underlying process-placement/circuit machinery remain available for inspection and later development.

The refined Process diagnosis is:

```text
Process Machine
= reusable Boundary First / Agentic Scientific Method operating grammar

Process Placement
= inferred or declared coordinate relative to that machine

Process Trace
= object-specific governed execution history through that machine
```

The current site has the first two and only a weak approximation of the third.

Future work should therefore preserve the generic machine, stop treating genericness itself as the primary defect, and build the missing trace substrate: recorded transitions, closure attempts, repair/reopen loops, artifacts crossing boundaries, evidence-triggered decisions, authority, promotion gates, and next admissible moves.

The intended longer-term composition is for Process Trace, Research Lane, Timeline, Evidence, and the Knowledge Transform Graph to reuse a shared governed event/transform substrate rather than maintaining incompatible workflow models.
