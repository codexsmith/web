# P4 Third-Layer Detail Surface Summary

P4 removes the two secondary interface worlds previously used for third-layer detail.

- Inspection no longer opens a modal/backdrop window.
- Graph-owned retained records no longer require a standalone landing renderer.
- Canonical objects retain identity and Boundary Frame context while deeper detail occupies the main content viewport.
- Legacy landing aliases redirect to the canonical graph owner when ownership is already declared by a node link.
- Agency & Representation Audit and Software Before Code receive specialized BFUX record compositions.
- Other owned records receive a structured transitional projection pending specialized treatment.

Core invariant:

> Object detail is a deeper representation of the current bounded object, not a new site and not a modal window.
